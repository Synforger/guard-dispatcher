# The promises the tests keep: one row is one thing the guard promises, and the test file that guards it.
#
# Format = <what keeps the promise> | <the test file> | <the promise, in one sentence>   (paths from the repository root)
# Checked by tests/contracts.bats (run with the suite, so by CI too): every test file under tests/ is in a row,
# and every row names a target and a test file that exist.
#
# A new test file comes with its row. A promise is said in what can be seen from outside: what is refused, what
# passes, what a command prints or writes. The guard is a guard: a test is removed only when no red it has seen
# is on record (the history of the test and of the code it guards), and a test that stopped a real defect keeps
# its row.
#
# Slow tests: the suite prints its ten slowest tests at the end (tests/setup_suite.bash). In Actions
# (run 46166091177, the whole suite 322 s on 4 cores) every slow one is a table of forms, each form a call of the hook:
#   6.0 s  area-guard.bats    an area path that stands by itself in code, or in what a command is fed, still marks
#   6.0 s  outgoing.bats      a send in arithmetic, a default, a function, a coprocess, a trap or a local ssh command
#   5.6 s  area-guard.bats    find, tar, unzip, -t and rsync on the transcripts' and the settings' folders
#   5.5 s  force-push.bats    a push that forces nothing goes as before
#   5.2 s  area-guard.bats    a path Python code only reads or turns into text is not a place it writes
#   5.1 s  ticket-places.bats peers.py is asked about the calling session only where it prints what that session read
#   4.9 s  outgoing.bats      a send inside a loop, a substitution, after a keyword or behind a program that runs it
#   4.8 s  area-guard.bats    inline code naming a relative path writes it where the command runs
#   4.7 s  script-files.bats  a script that writes where its argument says, naming the settings or a transcript
#   4.6 s  scanners.bats      a weekly-audit finding is reported until it is accepted
# Each form is a way round the guard someone found; they are kept whole, not cut to save the time.
